# Definition of Done

1. Todos os critérios de aceite têm evidência no entregável.
2. Há testes (ou plano de teste) cobrindo o fluxo principal.
3. Ações relevantes geram eventos de auditoria.
4. O entregável está salvo no workspace da sprint e foi verificado por alguém que não o desenvolveu.
5. O PO aceitou na Sprint Review.
