# User stories

- Formato: Como <persona>, quero <capacidade> para <valor>.
- INVEST: Independente, Negociável, Valiosa, Estimável, Pequena, Testável.
- 3 a 5 critérios de aceite, cada um verificável por observação (sem adjetivos vagos).
- Pontos Fibonacci (1,2,3,5,8,13). Maior que 8 → quebre a história.
